# NextGuide Add-ons

A dedicated place for creating and maintaining NextGuide add-ons, from simple documentation content to the future permissioned TypeScript/React extension system. Add-ons use the existing **single `nextguide` package**; there is no second SDK to install.

<Callout kind="info" title="What works today">
The developer publisher supports GitHub App sign-in, repository selection, preflight validation, submissions, updates, and withdrawal. Review is handled separately. The private ngapi registry signs its approved catalog. **Only content-only v1 add-ons can be published today.** The Account Mode marketplace installer and isolated executable runner are still in development.
</Callout>

## The add-on system we're building

| Function | Current state |
| --- | --- |
| Create and package Markdown content add-ons | Supported by the template |
| Publish, review, approve, update and withdraw add-ons | Working through ngapi Publisher |
| Signed registry and revocation | Working through ngapi |
| Capability contracts and trusted extension host | Available in NextGuide source |
| Host-mediated storage, signed catalog verifier, safe UI descriptors | Available as foundation APIs |
| Execute third-party React, TypeScript or server scripts | **Not supported yet** |
| Browse and install add-ons inside Account Mode | **Not supported yet** |

The extension host is not a security sandbox. Executable add-ons require a separate isolated runner, verified artifacts and owner-approved permissions before we can offer them in the marketplace.
