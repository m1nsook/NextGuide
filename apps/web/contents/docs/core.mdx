# Core utilities

The core helpers are included in the single `nextguide` package.

```ts
import { slugify, slugToTitle, sanitizeUrl, isExternalUrl } from "nextguide/core"
import type { NavItem, TocItem } from "nextguide/core"
```

| Export | Purpose |
| --- | --- |
| `slugify(text)` | Convert a title to a URL-safe slug |
| `slugToTitle(slug)` | Convert a slug into a human-readable label |
| `sanitizeUrl(url)` | Reject dangerous URL schemes |
| `isExternalUrl(href)` | Detect an external URL |
| `NavItem` | Navigation entry shared across documentation and API references |
| `TocItem` | Table of contents heading |

Use these APIs with [MDX](/docs/mdx) or [OpenAPI](/docs/openapi).
