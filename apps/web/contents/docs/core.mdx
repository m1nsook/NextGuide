# Core utilities

NextGuide ships reusable functions and types for links, routes, navigation and table of contents handling.

```ts
import { slugify, slugToTitle, sanitizeUrl, isExternalUrl } from "nextguide/core"
import type { NavItem, TocItem } from "nextguide/core"
```

`slugify` normalizes human-readable labels, while `sanitizeUrl` helps reject dangerous URL schemes. Navigation and TOC types are shared by the renderer and OpenAPI reference components.

There is **no separate core package to install**. These APIs are available through the single `nextguide` distribution.
