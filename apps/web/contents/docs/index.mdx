# NextGuide

NextGuide is an independent open-source **Next.js documentation framework**. Build MDX sites, publish OpenAPI references, and customize pages with reusable UI components, icons, and typography.

Install one package: `nextguide`. Core utilities, MDX rendering, OpenAPI, and UI components are included.

## Available today

- Next.js documentation with file-based MDX, navigation, search, and syntax highlighting.
- OpenAPI parsing and interactive API reference components.
- An all-in-one npm distribution with documentation components, shadcn-style UI, icons, and a font picker.
- Read-only static deployment, including this project's [GitHub Pages documentation](/docs/deployment/github-pages).

## On the roadmap

- A real `nextguide init` initializer for both Next.js routers.
- A secure owner-token setup wizard with a visual font picker.
- Optional Account Mode backed by embedded SQLite and an authenticated `/admin` panel.

**Current release:** `0.0.1-alpha.1` contains the renderer and components; the project initializer and Account Mode are not implemented.
