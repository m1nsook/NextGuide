# Documentation, built for your project

NextGuide brings MDX guides, API references, navigation, search, and reusable components into your Next.js application. Write content in files you own and deploy it with the tools you already use.

## Get started

<CodeTabs items={[{label:"Bun",code:"bun add nextguide@alpha\nbunx nextguide init --developer\nbun run dev",language:"bash"},{label:"npm",code:"npm install nextguide@alpha\nnpx nextguide init --developer\nnpm run dev",language:"bash"}]} />

Run these commands in a Next.js project. The initializer creates a documentation site under `/docs`; you can change the location during setup.

<Callout kind="info" title="Alpha release">NextGuide is currently on the npm alpha channel. The published alpha can differ from the in-development documentation and Account Mode preview. Check your installed version with `bunx nextguide --version`.</Callout>

## Choose a workflow

<LinkCards>
  <LinkCard title="Developer Mode" description="File-based MDX, source control, and static deployments" href="/docs/getting-started/developer-mode" />
  <LinkCard title="Account Mode" description="Browser-based configuration and editing, currently in development" href="/docs/getting-started/account-mode" />
</LinkCards>

**Developer Mode** is designed for people who prefer editing source files. It works with App Router or Pages Router and supports static builds.

**Account Mode** is an upcoming single-owner workflow for a persistent Next.js server. It adds an authenticator-based login, guided configuration, and a content editor. It is not part of the published alpha yet.

Both modes use the same `nextguide` package—not separate UI, MDX, and OpenAPI packages.

## Make it yours

Your documentation content lives in `content/docs/`, with `_meta.json` files controlling navigation. Built-in component examples are ready to use in MDX, and the theme and CSS can be customized inside your own application.
