# Welcome to NextGuide

Create a documentation site inside your existing Next.js app with one npm package. Choose how you want to work:

<LinkCards>
  <LinkCard title="Developer Mode" description="Write MDX in files, use Git, and deploy to static hosting." href="/docs/getting-started/developer-mode" />
  <LinkCard title="Account Mode" description="Set up and manage your site in a browser with a protected owner account." href="/docs/account" />
</LinkCards>

## Install in three steps

<CodeTabs items={[{label:"Bun",code:"bun add nextguide@alpha\nbunx nextguide init --developer\nbun run dev",language:"bash"},{label:"npm",code:"npm install nextguide@alpha\nnpx nextguide init --developer\nnpm run dev",language:"bash"}]} />

For browser-based editing, use `bunx nextguide init --account` instead. Account Mode needs an App Router project and a persistent Node.js server.

<Callout kind="info" title="Current package channel">NextGuide remains on the npm alpha channel. Features in the current source may not be available in every published alpha. Always check your installed version and the [release notes](https://github.com/m1nsook/NextGuide/releases).</Callout>
