# Documentation that belongs to your project

NextGuide is an independent, all-in-one documentation framework for Next.js. Your pages are **MDX files in your project**, not content trapped behind an external service. NextGuide takes care of loading them, creating navigation, rendering reusable components, and building API references.

## Install it, then edit it

<CodeTabs items={[{label:"Bun",code:"bun add nextguide@alpha\nbunx nextguide init --developer",language:"bash"},{label:"npm",code:"npm install nextguide@alpha\nnpx nextguide init --developer",language:"bash"}]} />

The initializer adds the route files, MDX content, navigation, configuration, and styles to an **existing Next.js application**. It detects `app/`, `src/app/`, `pages/`, or `src/pages/`; no copying a collection of examples into random directories.

## The two modes

**Developer Mode is available in the alpha installer.** It is file-first, Git-friendly, and suitable for static builds. NextGuide's own GitHub Pages site uses this kind of architecture.

**Account Mode is being developed.** It will add a secure first-run wizard, embedded SQLite, and an authenticated content editor. We will not pretend these features work before they do.

NextGuide is distributed as **one `nextguide` package**. Next.js and React remain peer dependencies; you do not need to install individual documentation libraries or run the shadcn registry installer.

<Callout kind="tip" title="Early alpha">The installer and expanded components are prepared for `0.0.1-alpha.2`. If your installed version is older, check `bunx nextguide --version` before following these instructions.</Callout>
