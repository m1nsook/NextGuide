# Static docs on GitHub Pages

NextGuide's official documentation is deployed to GitHub Pages as a **static Next.js export**, with no database, accounts, or admin backend.

## Configure your Next.js application

For a repository site at `https://yourname.github.io/your-repo/`, configure Next.js's `output: "export"` option and a matching `basePath` for your repository name:

```js
// next.config.mjs
const nextConfig = {
  output: "export",
  basePath: "/your-repo",
  trailingSlash: true,
  images: { unoptimized: true },
}
export default nextConfig
```

If you deploy to a root domain instead of a repository subpath, omit `basePath`. NextGuide's generated catch-all routes already enumerate documentation slugs for static generation.

## Build and publish

```powershell
bun run build
```

Upload the generated `out/` directory as a GitHub Pages artifact using your project's deployment workflow. In repository Settings → Pages, select **GitHub Actions** as the publishing source.

Our repository's own Pages workflow checks the package, builds its static docs, and publishes after merge to `main`. You can inspect that file at `.github/workflows/nextguide-pages.yml`.

**Account Mode cannot run on GitHub Pages.** It needs a server and persistent storage.
