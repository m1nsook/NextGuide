# Self-hosting

Developer Mode is part of your existing Next.js application. It doesn't require a separate NextGuide daemon.

## Production build

```powershell
bun install
bun run build
bun run start
```

Configure your reverse proxy and domain to point to the Next.js application. Keep `content/docs/` and the generated configuration tracked in your source repository.

For static hosting without a Node.js process, use Next.js `output: "export"` and deploy the `out/` directory. For dynamic Next.js hosting, run the production server normally.

Account Mode is planned separately and will require SQLite backups, secure admin sessions, and a persistent writable storage path. These account features are **not available in this alpha**.
