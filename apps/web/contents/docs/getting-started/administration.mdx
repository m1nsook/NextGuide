# Administration

**Status: planned.** The `/admin` routes are not implemented in the current development preview.

The Account mode administrator will use the same NextGuide design system as the public documentation.

## Planned sections

| Section | Purpose |
| --- | --- |
| Dashboard | Site overview, recent changes and shortcuts |
| Pages | Create, edit and organize MDX documentation |
| Navigation | Arrange documentation sections and page order |
| API reference | Upload and maintain OpenAPI documents |
| Media | Manage uploaded logos, images and files |
| Appearance | Colors, typography, theme, branding and favicon |
| Accounts | Administrator profile, avatar and credentials |
| Settings | Site metadata, URL, security and other preferences |

Credentials and sessions will be managed on the server. The administrator will require authentication, CSRF-safe mutations, server-side authorization and persistent storage.

Do **not** deploy the future Account mode administrator to GitHub Pages; Pages hosts the read-only documentation build only.

Read the [Account mode setup flow](/docs/getting-started/account-mode).
