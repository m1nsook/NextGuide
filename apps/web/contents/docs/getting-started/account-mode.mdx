# Account Mode is not released

Developer Mode is usable in the alpha. **Account Mode is still being developed** and is not a switch you can enable today.

The planned server installation will include an embedded SQLite database, a console-issued one-time ownership token, a protected `/setup` page, admin credentials, roles, and a content editor under `/admin`. The setup wizard will include live font previews and site branding.

Its database will live in a configurable, server-only persistent folder. Account Mode will require a Next.js server and will not run on static-only hosts such as GitHub Pages.

We will document the exact Account Mode installation commands only once they are implemented and tested from a locally installed `nextguide` npm package. In the meantime use [Developer Mode](/docs/getting-started/developer-mode).
