# Account Mode

Account Mode is for people who want to build and manage documentation in the browser. It uses the same NextGuide package as Developer Mode, but adds a private owner dashboard and persistent storage.

<CodeWindow title="Generate Account Mode" language="bash" code="bunx nextguide init --account" />

After generating the site, start your Next.js server, open `/setup`, and enter the one-time token printed by your terminal. Then register your authenticator and save the recovery codes.

## How Account Mode differs

| | Developer Mode | Account Mode |
| --- | --- | --- |
| Editing | Files and source control | Browser-based protected studio |
| Router | App Router and Pages Router | App Router |
| Hosting | Static export or Node.js | Persistent Node.js server |
| Authentication | Not required | Single-owner TOTP and recovery codes |
| Add-ons | Not available | Planned for 1.0.0 |

**Availability:** The source implementation includes both modes; check the published npm alpha version before following a new feature guide. The marketplace and add-on runtime are not available yet.
