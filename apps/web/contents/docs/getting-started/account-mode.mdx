# Account mode

**Status: planned.** Account mode will be the default installation experience once the NextGuide CLI is ready.

## First run

When the Next.js application starts without an installation, it will show a cryptographically random, one-time setup token in the terminal. The owner will visit `/setup`, enter that token, and then complete a guided wizard.

1. Verify ownership with the server-console token.
2. Choose website name, description, language, logo, favicon and public address.
3. Configure the accent color, light/dark appearance and typography.
4. Create the administrator account with username, email and password; choose Gravatar or an uploaded avatar.
5. Create an example or empty content structure and optionally import OpenAPI.
6. Review, confirm and lock the first-run setup.

The token must be stored hashed, rate limited, short-lived, and invalidated after use. Once installed, `/setup` must not be accessible to untrusted visitors.

## After setup

Sign in at `/admin` to create and edit pages, organize navigation, manage API specifications, upload media, and configure the site. Content will remain MDX-based wherever practical to preserve portability.

Account mode needs a **persistent Next.js server**; it cannot run on static-only GitHub Pages. See [self-hosting](/docs/deployment/self-hosting).
