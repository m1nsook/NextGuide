# Installation

NextGuide runs in **Next.js**. All documentation libraries, MDX tools, OpenAPI parsing, icons, and UI components are installed together—no separate documentation framework packages required.

## Install in an existing Next.js project

```powershell
bun add nextguide@alpha
```

Next.js and React are peer dependencies. The current CLI can diagnose an existing project:

```powershell
bunx nextguide@alpha doctor
bunx nextguide@alpha --version
```

## Import NextGuide

```tsx
import { createDocs } from "nextguide/mdx"
import { createOpenAPI } from "nextguide/openapi"
import { Docs, OpenAPI } from "nextguide/components"
import { Button, Card } from "nextguide/ui"
import { BrandIcon, UIIcon } from "nextguide/icons"
import "nextguide/styles.css"
```

For MDX components, use `nextguide/mdx/server` in Server Components or `nextguide/mdx/client` in Client Components.

These exports require version **0.0.1-alpha.1** or later. The earlier alpha.0 was a CLI-only preview.

## Develop NextGuide itself

Clone [NextGuide](https://github.com/m1nsook/NextGuide) using GitHub Desktop, then run from the repository root:

```powershell
bun install
bun run dev
```

Visit `http://localhost:4310`. To check the documentation build:

```powershell
bun run build:web
```

## Upcoming installation modes

The following commands are **planned, not yet implemented**:

```powershell
bunx nextguide init
bunx nextguide init --developer
```

The default will be Account Mode with a secure browser setup wizard, while Developer Mode will produce file-based documentation that can export to static hosting. This official documentation is a Developer Mode-style static site.

Read about [Developer Mode](/docs/getting-started/developer-mode) and [Account Mode](/docs/getting-started/account-mode).
