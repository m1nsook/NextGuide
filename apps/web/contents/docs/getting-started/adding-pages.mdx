# Write your first page

After running `bunx nextguide init --developer`, your docs live in `content/docs/`.

## 1. Create a file

Create `content/docs/changelog.mdx`:

```
---
title: Changelog
description: Release notes for our project.
---

# Changelog

## November 2026

We published our first documentation site using NextGuide.
```

## 2. Order it in the sidebar

Open the generated `content/docs/_meta.json` and add the new slug:

```json
[
  { "slug": "index", "title": "Introduction" },
  { "slug": "getting-started", "title": "Getting started" },
  { "slug": "changelog", "title": "Changelog" }
]
```

There are no route files to create for each new page. The NextGuide docs route automatically handles `/docs/changelog`.

## 3. Preview it

While your Next.js development server is running, visit `http://localhost:3000/docs/changelog` (use your actual dev port).

## 4. Use components in MDX

NextGuide ships a separate component library that you can import into your own Next.js components and pass into the MDX renderer. [Browse demos and matching source examples](/components/ui).

<Callout kind="info" title="MDX security">Trusted local MDX may include expressions. Content imported from untrusted accounts or a CMS must be treated differently; see [Rendering & security](/docs/mdx/rendering).</Callout>
