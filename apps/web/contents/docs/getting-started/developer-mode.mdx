# Developer mode

**Status: installer in development.** The official website already follows the file-first, read-only static-export architecture.

Developer mode manages MDX pages, navigation, themes, and OpenAPI specifications as versioned files. **It does not require SQLite, an owner account, sessions, or an admin backend.**

## Intended CLI workflow

~~~sh
bun add nextguide
bunx nextguide init --developer
~~~

These initialization commands are planned and not available in the published alpha.0 package yet.

## NextGuide's official documentation

The documentation at https://m1nsook.github.io/NextGuide/ is a **Developer Mode-style build**. The Next.js app exports static HTML and assets through GitHub Actions; it has no owner setup, database, or admin routes.

Today the project uses the NEXTGUIDE_PAGES=1 flag to enable static export and a /NextGuide base path. Once the developer-mode CLI can generate the same application, the site can adopt it without introducing server storage.

See [GitHub Pages](/docs/deployment/github-pages) for build details.
