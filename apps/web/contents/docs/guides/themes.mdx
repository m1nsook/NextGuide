---
title: Syntax themes
description: Colors for code blocks.
---

The same theme colors your MDX code blocks and the generated API examples. Importing the component styles includes the default theme:

```ts
import "nextguide/styles.css";
```

To use a different theme, import the base styles and the theme file:

```ts
import "nextguide/components/styles/theme.css";
import "nextguide/styles.cssss";
```

| Theme | File |
| --- | --- |
| Default | `styles/syntax/default.css` |
| GitHub | `styles/syntax/github.css` |
| Nord | `styles/syntax/nord.css` |
| Minimal | `styles/syntax/minimal.css` |

Every theme has dark colors that apply under a `.dark` class.

## Your own theme

Themes style Prism's token classes:

```css
.token.keyword { color: #c678dd; }
.token.string { color: #98c379; }
.token.property { color: #e06c75; }
.dark .token.keyword { color: #d19af0; }
```
