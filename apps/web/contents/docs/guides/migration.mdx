# Migrating to NextGuide

NextGuide uses a single npm dependency for MDX, OpenAPI, core utilities, and UI components.

```sh
bun add nextguide@alpha
```

Use `nextguide/mdx`, `nextguide/openapi`, `nextguide/core`, and `nextguide/components` instead of separate documentation libraries.

Account Mode and the initializer remain under development. For the supported alpha API, see [Installation](/docs/getting-started/installation).
