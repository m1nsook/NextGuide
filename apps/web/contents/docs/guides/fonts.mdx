# Typography

The package includes a `FontPicker` React component and a small catalog of families: Inter, Geist, IBM Plex Sans, Segoe UI, JetBrains Mono, Geist Mono, IBM Plex Mono and system fallbacks.

```tsx
import { FontPicker, DEFAULT_FONTS } from "nextguide/fonts"

export function TypographySettings() {
  return <FontPicker defaultValue={DEFAULT_FONTS} onChange={(fonts) => console.log(fonts)} />
}
```

The preview is interactive, but in **Developer Mode** the host application is responsible for saving font choices and applying them to its layout. The unreleased Account Mode source includes a site setup wizard with font selections, but it still requires production build validation. NextGuide uses Next.js font loading. System fonts such as Segoe UI are never redistributed with NextGuide.

For a static site, use `next/font/google` to self-host open fonts and connect the chosen CSS variables to your theme.
