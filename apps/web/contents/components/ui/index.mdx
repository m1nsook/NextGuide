# The component catalog

This is the actual NextGuide component library—not a list of components users must copy from another UI system. **The previews on these pages render the same JSX as the code samples.**

<CodeWindow title="Install the complete component library" language="powershell" code="bun add nextguide@alpha" />

```tsx
import { Button, Card, Dialog, Tabs } from "nextguide/ui"
import { CodeWindow, CodeTabs, FileTree } from "nextguide/blocks"
import "nextguide/styles.css"
```
