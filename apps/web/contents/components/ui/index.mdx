# NextGuide components

NextGuide includes **documentation components and a reusable UI library**. Every component is available through the same npm package, with TypeScript types and bundled default styling. No separate shadcn installation is necessary.

<Install packages="nextguide@alpha" />

```tsx
import { Button, Card, Dialog, Tabs, Table } from "nextguide/ui";
import { CodeWindow, CodeTabs, FileTree, Steps } from "nextguide/blocks";
import { Docs, OpenAPI } from "nextguide/components";
import "nextguide/styles.css";
```

The current public release is still in alpha. These additional UI and documentation blocks are being prepared for **0.0.1-alpha.2** and will not appear in previous versions.

## Design and accessibility

Interactive components use Radix primitives where appropriate. Others use accessible native HTML elements. UI styles are namespaced under `ng-` classes and can be customized with `--ng-*` CSS tokens. Import only the components you need; tree-shaking is supported by the ESM exports.

The library is growing toward broad BSIS.dev/shadcn component coverage. Some more complex widgets (charts, calendars, rich text editors, command palettes, and data grids) are not complete yet. The docs distinguish shipped components from upcoming ones.
