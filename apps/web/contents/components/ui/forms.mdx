## Multiline and selection

<Preview>
<div className="grid max-w-md gap-4">
  <div className="grid gap-2"><Label htmlFor="ng-demo-description">Description</Label><Textarea id="ng-demo-description" defaultValue="Documentation for my app." /></div>
  <div className="grid gap-2"><Label htmlFor="ng-demo-language">Language</Label><Select defaultValue="en"><SelectTrigger id="ng-demo-language"><SelectValue placeholder="Select a language" /></SelectTrigger><SelectContent><SelectItem value="en">English</SelectItem><SelectItem value="pl">Polish</SelectItem></SelectContent></Select></div>
</div>
</Preview>

```tsx
import { Label, Input, Textarea, Select, SelectTrigger, SelectValue, SelectContent, SelectItem, Switch, Checkbox } from "nextguide/ui"

<div className="grid max-w-md gap-4">
  <div className="grid gap-2"><Label htmlFor="ng-demo-description">Description</Label><Textarea id="ng-demo-description" defaultValue="Documentation for my app." /></div>
  <div className="grid gap-2"><Label htmlFor="ng-demo-language">Language</Label><Select defaultValue="en"><SelectTrigger id="ng-demo-language"><SelectValue placeholder="Select a language" /></SelectTrigger><SelectContent><SelectItem value="en">English</SelectItem><SelectItem value="pl">Polish</SelectItem></SelectContent></Select></div>
</div>
```

`Select` uses an accessible, keyboard-operated NextGuide dropdown with themed options. `NativeSelect` remains available only when an operating-system select menu is specifically desired.
