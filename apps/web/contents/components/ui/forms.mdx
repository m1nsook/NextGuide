# Forms & inputs

  <div className="grid max-w-md gap-5">
    <div className="grid gap-2"><Label htmlFor="ng-title-demo">Website title</Label><Input id="ng-title-demo" defaultValue="My Documentation" /></div>
    <div className="flex items-center gap-3"><Switch id="ng-theme-demo" defaultChecked /><Label htmlFor="ng-theme-demo">Allow theme switching</Label></div>

```tsx
import { Input, Label, Checkbox, Switch } from "nextguide/ui";

<Label htmlFor="site-title">Site title</Label>
<Input id="site-title" defaultValue="My Documentation" />

<Label htmlFor="theme-switch">Allow theme switching</Label>
<Switch id="theme-switch" defaultChecked />

<Checkbox id="table-of-contents" defaultChecked aria-label="Table of contents" />
```

You can also use `Textarea`, `NativeSelect`, `Field`, `FieldDescription`, `FieldError`, `RadioGroup`, `RadioGroupItem`, `Select`, and related selection primitives. Use labels and descriptions for accessible forms.
