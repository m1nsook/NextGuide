## One import path per group

```tsx
import { Button, Card, Tabs, Dialog } from "nextguide/ui"
import { CodeWindow, CodeTabs, FileTree, Callout } from "nextguide/blocks"
import { BrandIcon, UIIcon } from "nextguide/icons"
import "nextguide/styles.css"
```

The gallery uses live, working examples. Every JSX snippet beneath a demo represents **the same props and content** as the demo shown above it. No pseudocode disguised as a reusable implementation.
