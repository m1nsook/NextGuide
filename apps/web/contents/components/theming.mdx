# Theming components

NextGuide components use `ng-` classes and `--ng-*` tokens. The package stylesheet is a real CSS dependency, not a copy of another framework's legacy token names.

```tsx
import "nextguide/styles.css"
```

```css
:root { --ng-accent: #2196f3; --ng-radius: 0.45rem; }
[data-theme="dark"] { --ng-accent: #64b5f6; }
```

Use your own theme, font loading, and color palette in your Next.js app. View [colors & styles](/docs/guides/themes) for editable starter CSS and [typography](/docs/guides/fonts) for the font preview component.
